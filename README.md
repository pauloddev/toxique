# Toxique Moda

Landing page da Toxique Moda, loja de moda feminina em Mangabeira, João Pessoa - PB.

Site estático: abra `index.html` ou publique a pasta inteira (Netlify, Vercel ou GitHub Pages).

## WhatsApp

Os botões de WhatsApp ficam ocultos até o link ser configurado. No final do `index.html`, preencha:

```js
const WHATSAPP_URL = "https://wa.me/55DDDNUMERO";
```
